# Typography specimens

These boards compare open-source display candidates with identical Sudley Manor content. Petrona repeats as the control. Size, width, line breaks, color, evidence, and layout remain fixed so the display family is the primary variable.

- `petrona-neighbors.png`: closest direct challengers.
- `sturdy-editorial.png`: weight-bearing options for property evidence.
- `specialist-shelf.png`: expressive one-job faces, not default registers.

The boards are audition instruments, not templates. A candidate advances only after Andrew approves it here; finalists then receive real cover, evidence, finale, and mobile tests.
